# 🚀 MarketForge AI

A production-grade **Autonomous Multi-Agent Marketing Platform** that acts as your personal AI-driven marketing agency.

---

## 🎯 What is MarketForge AI?

MarketForge AI autonomously generates, edits, and audits full-scale marketing campaigns based on simple user prompts. Instead of struggling with writer's block or juggling different AI chats, you specify your product and target audience, and the AI swarm builds your strategy, content calendar, and assets (tweets, newsletters, blog posts) automatically.

---

## 🤖 The AI Marketing Swarm

The platform operates using three highly specialized AI agents collaborating in a pipeline:

| Agent Role | Responsibility |
| :--- | :--- |
| **The Strategist** | Maps out target demographics, core brand voice, and a comprehensive 30-day content strategy calendar. |
| **The Copywriter** | Consumes the strategy plan and writes highly engaging, markdown-formatted marketing assets (Tweets, Newsletters, Blog Posts, Ads). |
| **SEO & Brand Reviewer** | Audits the generated copy, scores it out of 100 for SEO effectiveness, and enforces strict brand safety and tone guidelines. |

---

## 🛠️ Technology Stack

- **Frontend Environment**: React 19, TypeScript, Vite, Tailwind CSS, Lucide Icons, Framer Motion
- **Backend Architecture**: FastAPI, Python 3.11+, SQLAlchemy Async ORM
- **Database**: SQLite (built-in, zero configuration)
- **Authentication**: JWT-based Secure Auth & SMTP/Resend Email Password Reset
- **LLM Engine**: Ollama (defaults to `qwen3:8b`, fallback supported)

---

## ✨ Features

- **Interactive Workspace Explorer**: A VS Code-like studio for viewing, downloading, and directly editing your generated marketing `.md` assets.
- **Real-time Swarm Chat**: Instruct the agents dynamically in the chat to revise copy or draft new assets on the fly.
- **Dynamic SEO Dashboards**: The frontend recalculates and monitors your SEO audit scores in real-time as the agent modifies your files.
- **Persistent Ledger Tracking**: A secure internal session-ledger that strictly counts every single word generated by the AI across all your active campaigns.
- **Kanban Task Manager**: Seamlessly track the progress of your campaign deployment and assign new tasks directly to specific agents.

## ⚡ Quickstart Setup

### 1. Backend Setup

```bash
cd backend
# Create a virtual environment and install dependencies
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt

# Run the FastAPI server
uvicorn app.main:app --reload --port 8000
```

### 2. Frontend Setup

```bash
cd frontend
# Install node modules
npm install

# Start the Vite development server
npm run dev
```

### 3. LLM Setup
Ensure you have [Ollama](https://ollama.com/) running locally:
```bash
ollama run qwen3:8b
```
*(You can also configure remote API keys through the frontend UI or `.env` file!)*

## 📦 Exporting Assets
Once a campaign has finished generating, click the **Download Campaign Assets** button in the dashboard to instantly package the entire file registry (including all strategy documents and social media drafts) into an organized `.zip` archive!
